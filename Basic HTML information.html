HTML

Full form of HTML is HyperText Markup Language. HTML is the foundational scripting language used by web browsers to display content on the World Wide Web. HyperText in HTML allows users to navigate the web by clicking links that redirect to new pages. Markup in HTML involves using tags to define how text and images are presented on a webpage.

11) Use of <section> tag:

The section element is a structural HTML element used to group together related elements. Each typically element includes one or more heading elements and additional elements presenting related content.

12) Use of <nav> tag:

The nav tag in HTML is used to define a set of navigation links. It's a semantic element that helps search engines and screen readers understand the structure of a webpage.

13) Use of <header> tag:

The header tag in HTML is used to define a header section for a document, section, or article. It typically includes introductory content, navigation, or branding elements.

14) Use of <footer> tag:

The footer tag in HTML is used to define a footer section for a document, section, or article. It typically includes information such as: Copyright information, Contact details, Social media links, Site map or navigation links, Author information.

15) Use of <aside> tag:

The aside tag in HTML is used to define content that is tangentially related to the main content, such as: Sidebars, Callouts, Additional information, Quotes or pull quotes, Author bios, Related links.

16) Use of <style> tag:

The style tag in HTML is used to define internal CSS styles for a document. It allows you to apply styles directly within the HTML document, rather than linking to an external stylesheet.

17) Use of <sup> tag:

Superscript is oftenly used in writing of classes, equations, and many more such as 12th, 1st, x3+x2+x+1=9, etc.

18) Use of <sub> tag:

Subscript is oftenly used in writing of chemical equations, and many more such as Fe+ CuSO4--> FeSO4+Cu, (H2SO4)3, etc.
